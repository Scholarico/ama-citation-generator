# AMA Citation Generator Widget

An open-source, lightweight JavaScript generator for 11th Edition American Medical Association (AMA) citations. Designed for fast integration into academic blogs, research platforms, and publisher sites.

## Live Demo & Online Tool
You can use and test the live production version of this tool directly at [Afromag AMA Citation Generator](https://afromag.com.ng/ama-citation-generator/).

## Features
- Formats journal articles, web sources, and academic papers into standard AMA 11th Edition style.
- Pure JavaScript and HTML with zero external dependencies.
- Instant copy-to-clipboard functionality.
